# Analytics

## MVP metrics

Per carousel:
- impressions
- views
- likes
- comments
- shares
- saves
- clicks
- publish status

## Derived metrics

- engagement rate
- share rate
- save rate
- click-through rate
- view completion where supported

Do not compare metrics across platforms without clearly defining differences in measurement.

## Feedback loop

Analytics should eventually inform:
- formats that perform well
- hooks that perform well
- slide counts
- CTA patterns
- posting cadence

Do not automatically claim that a format is universally viral. Treat performance as account-, audience-, platform-, and time-dependent.

## Dashboard

MVP:
- total posts
- total views
- engagement
- clicks
- recent posts
- top-performing posts

Later:
- format analysis
- hook analysis
- cohort analysis
- experiment tracking

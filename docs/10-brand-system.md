# Brand System

## Brand kit

A workspace can define:
- product name
- description
- audience
- positioning
- tone
- words to use
- words to avoid
- logo
- colors
- fonts
- image style
- CTA
- website
- social handles
- proof points

## Brand context for agents

Agents should receive a compact brand context rather than an entire database record.

Example:

```text
Product: Example
Audience: indie founders
Positioning: analytics without setup
Tone: sharp, technical, direct
Avoid: hype, fake urgency, corporate jargon
CTA: Try Example
```

## Brand enforcement

The validator should detect:
- off-brand colors
- missing logo where required
- forbidden phrases
- unsupported claims
- inconsistent product naming

## Multi-brand workspaces

Each project selects one brand context.

Agents must not mix brand data across projects.
